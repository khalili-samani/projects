# Data Analytics Portfolio

I'm a data professional with an MPhil in Mathematics from the University of Melbourne, with interests in data analytics, data engineering, statistical modelling and practical problem-solving.

This repository brings together my independent projects using Python, SQL, Power BI, Excel and other analytical tools. The projects cover areas including Australian electricity markets, healthcare operations, retail performance, property data and financial markets.

My focus is on building reliable analytical workflows, working carefully with imperfect data, and communicating findings in a way that is useful and technically sound.

## Featured Projects

### 1. Australian Electricity Market: Price and Demand Analytics

**Python | Pandas | MySQL | SQL | Matplotlib**

[View project](./aus_energy_automation)

An end-to-end analytics pipeline using publicly available data from the Australian Energy Market Operator (AEMO).

The project retrieves, cleans and stores five-minute electricity price and demand observations, then uses SQL and Python to examine regional price patterns, volatility and negative-price frequency.

The March 2026 analysis covers 26,784 observations across Victoria, New South Wales and Queensland.

**Key finding:** Victoria recorded the lowest average wholesale price of the three regions ($44.74/MWh), but the highest price standard deviation ($49.45/MWh). Prices were negative in 25.44% of its five-minute intervals.

### 2. Retail Sales and Profitability Analysis with Power BI

**Power BI | Power Query | DAX | Data Modelling**

[View project](./dfo_sales)

A five-page Power BI report analysing 6,200 synthetic retail transactions.

The project covers data cleaning, dimensional modelling, KPI development and reporting across sales, profitability, products, promotions, staff and customer segments.

The report uses a star schema, reusable DAX measures and reconciliation checks to support consistent analysis.

**Key focus:** Understanding business performance beyond revenue by examining margins, discounts, returns and customer behaviour.

### 3. Australian Housing Data Quality and SQL Analytics Warehouse

**MySQL | SQL | Python | Data Warehousing**

[View project](./australian_housing_mysql_analytics)

A SQL analytics warehouse designed to process deliberately imperfect Australian housing data generated by a separate Python project.

The workflow covers raw ingestion, standardisation, duplicate handling, data-quality validation, dimensional modelling and reporting marts.

It includes analytical SQL using window functions, common table expressions, reconciliation checks and documented transformation rules.

**Key focus:** Building structured and auditable analytical datasets from unreliable source records.

### 4. Queensland Elective Surgery Capacity and Waitlist Recovery Optimiser

**Python | DuckDB | Parquet | Google OR-Tools | Data Engineering**

[View project](./qld-elective-surgery-optimiser)

A data engineering and mathematical optimisation project exploring how hypothetical additional elective surgery capacity could be allocated across Queensland facilities and services.

The system combines public data ingestion, validation, lineage tracking, analytical modelling and constrained optimisation.

It distinguishes observed healthcare data from synthetic scenario assumptions and modelled allocation decisions.

**Current status:** The implemented phases have automated test coverage, with 143 tests reported as passing locally. Live end-to-end processing of current Queensland Government resources remains to be verified.

## Data Sources and Limitations

The projects use a combination of publicly available real-world datasets and synthetic data created for analytical and engineering demonstrations.

Projects using real Australian public data include the electricity-market analyses and the Queensland elective surgery project.

The retail, housing and emergency department projects use synthetic datasets. Their reported findings are illustrative and should not be interpreted as actual market, business or healthcare performance.

Each project has its own README describing the methodology, implementation, results and relevant limitations.

These are independent portfolio projects rather than systems deployed for commercial or clinical use.
